# LiveLens

Экранный переводчик на Qt/C++.

Программа делает скриншот экрана или выбранной области, распознаёт английский текст через Tesseract OCR и переводит его на русский. Поддерживается обычный онлайн-перевод, технический режим с терминологической обработкой и пользовательские словари.

## Возможности

- захват всего экрана;
- захват выделенной области;
- захват текста рядом с курсором;
- OCR через Tesseract;
- онлайн-перевод через локальный LibreTranslate;
- обычный режим перевода;
- технический режим перевода;
- пользовательский словарь для каждого режима;
- добавление слова в словарь через выделение области на экране;
- окно словаря с возможностью добавлять, удалять и очищать слова;
- всплывающее окно с оригиналом и переводом.

## Требования

- Qt 5/6;
- C++17;
- vcpkg;
- Tesseract OCR;
- Leptonica;
- Python;
- LibreTranslate;
- модель перевода Argos Translate `en -> ru`.

## Настройка vcpkg

Нужно задать переменную среды `VCPKG_ROOT`.

Пример:

```text
VCPKG_ROOT=D:/vcpkg/vcpkg
```

В проекте путь к vcpkg берётся из этой переменной среды, поэтому прямой путь к vcpkg в `scrtransl.pro` не хранится.

## Настройка Tesseract

Для распознавания текста используется Tesseract OCR.  
Приложению нужна папка `tessdata`, в которой должен лежать файл английской языковой модели:

```text
eng.traineddata
```

Есть два способа указать путь к `tessdata`.

### Способ 1: положить `tessdata` рядом с exe

После сборки проекта рядом с исполняемым файлом должна быть папка:

```text
scrtransl.exe
tessdata/
└── eng.traineddata
```

### Способ 2: указать переменную среды `TESSDATA_DIR`

Можно задать переменную среды:

```text
TESSDATA_DIR=D:/tessdata
```

Если папка находится в другом месте, нужно указать свой путь.

Приложение сначала проверяет переменную `TESSDATA_DIR`.  
Если она не задана, программа ищет папку `tessdata` рядом с exe-файлом.

В репозиторий проекта папка `tessdata` не добавляется, потому что языковые модели являются внешними файлами.

## Настройка LibreTranslate

Установить LibreTranslate:

```bash
pip install libretranslate
```

Установить модель английский -> русский:

```bash
python -c "import argostranslate.package as p; p.update_package_index(); p.install_package_for_language_pair('en','ru'); print('Installed en->ru')"
```

Запустить сервер LibreTranslate.

Обычный вариант:

```bash
libretranslate --load-only en,ru
```

Если команда `libretranslate` не находится, можно запустить через полный путь, например:

```bat
D:\Python\Python313\Scripts\libretranslate.exe --load-only en,ru
```

После запуска сервер должен быть доступен:

```text
http://127.0.0.1:5000
```

Окно с запущенным LibreTranslate закрывать нельзя, пока работает приложение.

## Пользовательские словари

В приложении есть два пользовательских словаря:

- обычный словарь;
- технический словарь.

Выбор словаря зависит от выбранного режима перевода.

В окне словаря можно:

- добавить английское слово;
- автоматически получить обычный перевод;
- вручную изменить перевод;
- удалить выбранное слово;
- очистить словарь.

Также можно добавить слово через выделение области на экране. В этом случае программа распознаёт выделенное слово и предлагает сохранить его перевод в словарь текущего режима.

## Сборка

1. Открыть `scrtransl.pro` в Qt Creator.
2. Задать переменную среды `VCPKG_ROOT`.
3. Задать `TESSDATA_DIR` или положить `tessdata` рядом с exe.
4. Запустить qmake.
5. Собрать проект.
6. Запустить LibreTranslate.
7. Запустить приложение.

## Что не входит в репозиторий

В репозиторий не добавляются:

- папки сборки;
- `.exe`, `.dll`, `.obj`;
- `tessdata`;
- Python;
- LibreTranslate;
- модели Argos Translate;
- временные скриншоты.

Эти файлы являются внешними зависимостями или результатами сборки.
